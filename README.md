# Adaptive LASSO Feature Selection using Dynamic Soft-Thresholding

This project implements a Dynamic Soft-Thresholding Proximal Gradient
method for sparse feature selection in high-dimensional regression.

## Dataset
House Prices: Advanced Regression Techniques

## Models Implemented
- Ridge Regression
- LASSO Regression
- Dynamic Adaptive LASSO (Proposed Method)

## Evaluation Metrics
- Mean Squared Error (MSE)
- Feature Sparsity
- Runtime Efficiency
- Loss Convergence

## Results
The proposed dynamic LASSO method achieves better sparsity while
maintaining competitive prediction accuracy compared to standard
Ridge and LASSO models.
